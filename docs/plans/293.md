# #293: CI template v1.48 adoption

Objective: bring the workflows to the handbook templates (ci.yml v1.48,
nightly.yml v1.12, signatures.yml v1, revert-red-main.yml v1.3), keeping this
repository's Kotlin/Gradle jobs and every CUSTOMIZE value it already holds.
Push triggers stay limited to main (and v* tags).

## Slices, in order (one commit each)

1. This plan.
2. revert-red-main.yml to v1.3: the v1.2 repository variables
   (AGENT_LOGIN, AGENT_DOMAIN) and the v1.3 header over the current file,
   which already has the v1.3 timeout. Kept: REVERT_STEPS for the Android
   stages, CLOSING_LINK, and the resumable, idempotent recovery blocks.
   Test: actionlint, scripts/revert-red-main-test.sh (make lint-gates).
3. ci.yml to v1.48: the `ci-template: v1.48` header with one adapted line
   per deviation; preflight's runner and runner_docker outputs, the
   image-building jobs reading runner_docker and CI Gate reading runner, and
   `Free runner disk` only on a hosted runner. Adapted: no overflow to a
   self-hosted pool. The repository is public with no self-hosted runners
   registered, and a fork's pull request must never reach one, so preflight
   always outputs ubuntu-latest; the overflow env, the actions: read
   permission, the `Mask the LAN addresses` step and scripts/ci-mask-lan.sh
   (which serve only that path) are left out. Kept: the Gradle jobs and
   Makefile targets, the hermetic gate, APT_INDEX_SUM / apt-index-sum.sh, the
   integration apt-get upgrade and image-tag-test. Test: actionlint; no job
   in ci.yml, nightly.yml, signatures.yml or revert-red-main.yml resolves
   runs-on to a self-hosted label on GitHub.
4. nightly.yml (v1.12): Go-only jobs dropped and named in the header's
   adapted line; the rest calls existing Makefile targets. Test: actionlint,
   make -n on each target.
5. signatures.yml (v1): the commit signature gate as its own workflow;
   ci.yml drops its signatures job and CI Gate's line for it. Test:
   actionlint. (Landed before slices 3 and 4.)

Every slice: ./gradlew :app:testDebugUnitTest still passes (no app change).

## Out of scope

- Template jobs that only make sense for Go (named in each header).
- Companion scripts the template ships for Go builds; any job that would
  need one is reported, not added.
- code-review.yml: it is adopted from its own template (bumped separately)
  and keeps that template's runner selection, so the hosted-only rule here
  covers ci.yml, nightly.yml, signatures.yml and revert-red-main.yml only.
  This row leaves code-review.yml unchanged.
