# Plan: SPEC row media-signing (#258)

## Objective

Ship SPEC row `media-signing`: a foreground service watches MediaStore,
hashes new photos and videos, signs them and embeds the signature in EXIF
or XMP, with an auto-sign toggle and key choice. Videos and PNG/WebP photos
embed the signature in XMP, not in a sidecar file (#200).

## Slices, in order

1. Fold PR #212 (`row/200-media-xmp-embed`, head f1081069) with
   `git merge --no-ff`. One conflict, in `ui/FileOperationActivity.kt`
   (the field block after `pickSidecarLauncher`). Resolution: keep main's
   staging fields (`staging`, `pendingEncryptedSave`, `pendingDecryptedSave`,
   from #205) and add #212's `createSignedCopyLauncher`, `PendingSignedCopy`
   and `pendingSignedCopy`. Drop #212's `pendingEncryptedUri` and
   `pendingDecryptedUri`; main's PendingStagedSave replaces them.
   Tests that come with it: XmpContainersTest, XmpMetadataHelperSidecarBranchTest,
   AutoSignHashTest, MediaHasherCanonicalTest, and the instrumented
   XmpMetadataHelperInstrumentedTest.
   Done: merged with that resolution.
2. Run the media and ui unit tests (`testDebugUnitTest`) on the merged tip.
   The Makefile has no per-feature integration target; `make
   integration-test` (connectedDebugAndroidTest, incl.
   XmpMetadataHelperInstrumentedTest) needs a device, so CI runs it.
3. docs/SPEC.md already lists the row as shipped; the PR body ticks #200/#212

## Out of scope

- New signing formats beyond EXIF (JPEG) and XMP (video, PNG, WebP).
- Desktop-side verification changes (go-xkms).
