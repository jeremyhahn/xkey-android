# 214: audit a PIV certificate import

## Objective

Since #186 `PivKeyManager.importCertificate` parses the certificate and
refuses one whose key is not the slot's live Keystore key, but a stored
certificate leaves no audit record: `AuditLogger.logPivCertImported` has no
caller. Key generation and signing in a slot are audited; the import must be
too.

## Slices

1. Failing tests in `PivKeyManagerTest`:
   - a successful import writes exactly one `logPivCertImported` naming the
     slot (`9A`) and the certificate subject;
   - a certificate refused for its key, or bytes that do not parse, write none;
   - with `AuditLogger` not initialized (real object, no DAO) the import
     still stores the certificate.
2. `importCertificateLocked` calls `AuditLogger.logPivCertImported(slot.hexId,
   subject)` once, after the upsert succeeds; refusals throw before it.
3. `docs/piv/architecture.md` names the import's audit call.

## Out of scope

- `AuditLogger` and the PIV GATT handler (unchanged).
- Auditing refused imports (no failure variant of the event exists).
