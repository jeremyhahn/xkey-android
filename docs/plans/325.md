# Plan for #325: docs match the shipped app (keys)

## Objective

Every statement in the key and crypto docs folders is true of the code on
main, and the prose reads as if an engineer wrote it by hand.

## Slices, in order

One commit per folder, "docs: <folder> matches the shipped code":

1. docs/hardware-backed-keys
2. docs/exportable-symmetric-keys
3. docs/key-sharing
4. docs/certificate-authority
5. docs/protected-memory
6. docs/device-attestation
7. docs/user-verification
8. docs/fido2-built-in-uv
9. docs/fido2-phone-backend
10. docs/release-signing

For each folder: check class, file and RPC names, flows, limits, error
codes, settings and screen names, Android versions and hardware needs
against app/src/main and app/build.gradle.kts; fix what is wrong; apply
the writing rules from the brief.

Before the last commit, run the word and em dash grep from the brief over
the ten folders and fix every prose hit.

## Checks

This is a docs-only row with no code change, so it adds no tests. The
acceptance checks are: every path a doc names exists on main, the grep
has no prose hits, and there is one commit per folder.

## Out of scope

docs/SPEC.md, ROADMAP, other plans, code, and every docs folder not
listed above. SPEC wording problems go in the lane report.
