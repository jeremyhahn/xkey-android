`org.bouncycastle:bcprov-jdk18on` and `bcpkix-jdk18on` 1.86 are behind
1.87, and 1.87 is now past the 7-day settling window. Bump the shared
`bouncycastle` version so deps-check passes again.

## Cause

Bouncy Castle 1.87 was released and the settling window passed; the
catalogue still pins 1.86. No code defect.
