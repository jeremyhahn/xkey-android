# #127: clamp the toolchain image container CPUs to the Docker daemon

- Error: `scripts/in-toolchain-image.sh` passes `--cpus N` from the job's cgroup
  quota or `nproc`; when N exceeds the daemon's CPUs, `docker run` refuses it
  ("range of CPUs is from 0.01 to M"), and the stage fails before it starts.
- Clamp: after the positive-integer check, read `docker info --format '{{.NCPU}}'`;
  when it is a positive integer below N, N becomes that count. GOMAXPROCS and
  GOFLAGS=-p follow N.
- Acceptance: `bash -n` and `shellcheck` pass on the script; `make lint-gates`
  passes; the module proxy list still ends without the direct fallback (#125).
