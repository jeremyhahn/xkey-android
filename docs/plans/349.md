# 349: tests for desktop pairing over TCP and USB streams

## Objective

`StreamPairingSession` runs the identity exchange, the Noise XX handshake,
pairing.confirm with its short authentication string and the gate that
refuses an unpaired peer, for every desktop on TCP or USB. Its JVM tests
cover revocation and the no-store gate. This row adds plain JVM tests, over
loopback sockets, for the identity exchange, the pairing.confirm decision
table, the unpaired gate and the frame-loop limits, and keeps apart the key
a peer CLAIMS (identity message, pairing.confirm params) from the key the
handshake AUTHENTICATES.

## Slices, in order

1. `StreamIdentityExchangeTest`: known-device ack with the stored
   fingerprint and the prologue binding; an empty prologue after a known ack
   fails the handshake; unknown key, fingerprint of the wrong length or not
   hex get `0x00`; version `0x02`, 32- and 34-byte first frames are msg1 (no
   ack); identity of paired A then handshake as unpaired B stays gated;
   garbage msg1 and msg3 end only that connection.
2. `StreamPairingConfirmTest`: approve, uppercase claimed key, claimed key
   differs from the handshake key, user rejects, no callback, already paired
   (no prompt, `confirmAlreadyPaired`), missing and invalid params, the gate
   for normal, transport-method and string-id requests with `id` and
   `generation` echoed, a response frame before pairing.
3. `StreamFrameLimitsTest`: more than 16 frames behind a blocked request,
   replayed, corrupted and zero-length frames, a response over 65535 bytes,
   and the next desktop served after each.
4. `StreamMessageFramingTest`: zero length, `0xFFFF`, split header, a
   one-byte header, an oversized write leaves the stream untouched.
5. Any bug: a commit with only the failing test, then the fix.

## Out of scope

The device tests in `app/src/androidTest` (not repeated), BLE GATT, the
revocation test file (an open pull request changes it), and fixes in files
outside `StreamPairingSession.kt` and `StreamMessageFraming.kt`: those are
reported, not made.
