# #274: deps-check fails on mockk

## Objective

`make deps-check` fails on every PR and on main: io.mockk:mockk and
io.mockk:mockk-android 1.14.11 are behind 1.14.12.

## Cause

mockk 1.14.12 is now older than the 7-day settling window in
`scripts/deps-check.sh`, so being behind it turned from a report line into a
FAIL line. No code changed; the calendar did.

## Slices

1. This plan.
2. Bump the `mockk` version ref in `gradle/libs.versions.toml` from 1.14.11 to
   1.14.12 (covers both `mockk` and `mockk-android`).
   Tests: `make deps-check` prints no FAIL; `./gradlew :app:testDebugUnitTest`
   and `make it-jvm-test` pass. A test that breaks on 1.14.12 is fixed in the
   test, never in production code.

## Out of scope

- bouncycastle 1.87 and robolectric 4.18: under 7 days old, report lines only.
- Any production code change.
