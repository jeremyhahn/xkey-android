# #298: deterministic USB slot reattach tests (usb-transport)

## Objective

Make `a slow teardown of the detached session keeps the new peer identity`
in `UsbAccessoryServerSlotTest` deterministic. It failed once in a full
unit-test run on a loaded machine with `the reattach was ignored`.

## Slices

1. Test first: the reattach case drives the slot's teardown wait itself.
   It learns through a signal (not a sleep) that the reattach waits on the
   old session's teardown, releases the teardown, and joins the reattach
   with no bound, so no wall clock decides the outcome.
2. Fix at one choke point: `UsbAccessoryServerSlot.open`'s wait for the
   retiring session becomes an injectable `awaitTeardown`; production keeps
   the bounded join with the same timeout. Both reattach cases use it.

## Out of scope

Other USB behaviour, other flaky tests, the teardown timeout's value.
