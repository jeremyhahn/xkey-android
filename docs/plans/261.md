# #261: main does not compile its unit tests (red main 1abb4747)

## Cause

#239 (HmacEcdhAuditTest) and #165 (accessory detach/reattach) were each green
alone. #165 made `connectionId` a required parameter of
`RequestHandler.servedConnection`; #239 added a test helper that calls it with
two arguments. Combined on main, `:app:compileDebugUnitTestKotlin` fails.

## Slice (one)

1. `HmacEcdhAuditTest.servedBy` passes a connection id
   (`"test:connection"`), as the other test callers do.
   - Sweep: app/src/test and app/src/androidTest hold no other two-argument
     call of `servedConnection`.
   - Tests: `:app:compileDebugUnitTestKotlin`, `HmacEcdhAuditTest`,
     `make it-jvm-test`.

## Out of scope

Production code: no change.
