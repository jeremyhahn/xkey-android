# #225: deps-check exempts Robolectric's android-all-instrumented

## Objective

`make deps-check` fails on `org.robolectric:android-all-instrumented`: the
jar's version names the Android API level it instruments (`14-robolectric-…`
is API 34), so its newest release is always the newest API level, not a
newer build of the one the tests run. The tests run on targetSdk 34, so the
jar is pinned there and moves only with a targetSdk bump. Exempt it, with
that reason, and nothing else in `org.robolectric`.

## Slices

1. This plan.
2. `scripts/deps-check-exempt.txt` gains one line for
   `org.robolectric:android-all-instrumented` with its reason.
   `scripts/deps-check-test.sh` evaluates fixture reports against the
   project's own exempt file: the behind `android-all-instrumented` (an old
   API 36 release) is exempt, and `org.robolectric:robolectric`, behind an
   old release in the same group, still fails. The fixture helpers take a
   group (default `com.example`).

The matcher in `scripts/deps-check.sh` compares the exempt key with the
report's `group:name`, never the version, so a versioned artifact needs no
matcher change.

## Out of scope

- Bumping targetSdk or the android-all-instrumented pin.
- Any other exemption.
