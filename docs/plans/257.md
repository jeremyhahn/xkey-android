# Plan: SPEC row usb-transport (#257)

## Objective

Deliver row `usb-transport` of docs/SPEC.md: USB accessory (AOA) with a
2-byte big-endian length prefix, sharing the `StreamPairingSession`
responder with TCP. The framing and the shared responder are on main; the
row's open item is accessory detach and reattach (#134, PR #165).

## Slices

1. Fold PR #165 (`row/134-usb-detach`, already merged with main adfc48ff)
   into this row branch with a merge commit. It brings:
   - `UsbAccessoryServerSlot` and `AccessoryDetachWatcher`: a detach closes
     the session and lets it finish its teardown; a reattach starts a new
     server; a clear refuses a pending open.
   - Per-request connection ids and owner-scoped peer identity clear in
     `StreamPairingSession`, so a late teardown keeps the reattached
     desktop's identity.
   - PER_SESSION approval prompts again after a reattach inside the
     Keystore window.
   - docs/usb-transport/architecture.md on detach and reattach.
   Tests it adds: `UsbAccessoryServerSlotTest`, `UsbAccessoryServerTest`,
   `PeerIdentityTeardownTest`, `PerSessionApprovalReattachTest`, and the
   BLE service's late-attach race test.
2. Merge main 9e486ed. Main now carries #165 itself (7cc5975), so the
   fold leaves the row branch equal to main apart from this plan; #134
   and #165 are done there.
3. Run the unit tests of the usb, transport, protocol, tcp and ble
   packages on the merged tip.
